# 模块化配套代码

这些示例按知识点拆分，可以逐个运行。

## Node.js 示例

在当前目录运行：

```bash
node ./01-basic/main.mjs
node ./02-live-binding/main.mjs
node ./03-execution-order/main.mjs
node ./04-dynamic-import/main.mjs
node ./05-commonjs/main.cjs
node ./06-football-app/main.mjs
```

`.mjs` 表示 ES Module，`.cjs` 表示 CommonJS，不需要额外修改 `package.json`。

## 浏览器示例

`07-browser/index.html` 使用原生 ES Module。请通过 VS Code Live Server 等本地服务器打开，不建议直接双击 HTML。

## 推荐学习顺序

1. `01-basic`：命名导出、默认导出和改名。
2. `02-live-binding`：理解导入不是静态复制。
3. `03-execution-order`：观察依赖先于入口执行。
4. `04-dynamic-import`：理解 `import()` 返回 Promise。
5. `05-commonjs`：对比传统 Node.js 模块。
6. `06-football-app`：学习真实项目拆分。
7. `07-browser`：在浏览器中使用模块。
