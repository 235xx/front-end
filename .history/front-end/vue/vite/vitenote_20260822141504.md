Vite笔记：

路径别名：@，把长相对路径映射成稳定的项目路径，重构目录时更少牵连。
import { fileURLToPath, URL } from 'node:url'
resolve: {
alias: {
'@': fileURLToPath(
new URL('./src', import.meta.url)
),
},
},

开发服务器替浏览器转发请求，解决本地开发时的跨域与地址差异。
server: {
proxy: {
'/api': {
target: 'http://localhost:3000',
changeOrigin: true,
},
},
},

插件进入 Vite 的转换生命周期，读取源码后生成对应导入与类型声明。
plugins: [
vue(),
AutoImport({
imports: ['vue'],
}),
Components({
resolvers: [ElementPlusResolver()],
}),
],
