Vite笔记：

路径别名：@，把长相对路径映射成稳定的项目路径，重构目录时更少牵连。
import { fileURLToPath, URL } from 'node:url'
resolve: {
alias: {
'@': fileURLToPath(
new URL('./src', import.meta.url)
),
},
},

开发服务器替浏览器转发请求，解决本地开发时的跨域与地址差异。
server: {
proxy: {
'/api': {
target: 'http://localhost:3000',
changeOrigin: true,
},
},
},

插件进入 Vite 的转换生命周期，读取源码后生成对应导入与类型声明。
plugins: [
vue(),
AutoImport({
imports: ['vue'],
}),
Components({
resolvers: [ElementPlusResolver()],
}),
],

环境变量实验：
.env.production 会覆盖 .env 中的同名变量
带 VITE\_ 的变量会进入浏览器，不能存密码或密钥

TypeScript:
Props 定义输入，Emit 定义输出；父子组件据此安全协作
Props
声明别人如何使用我
Ref
声明响应式值装什么
Emit
声明我会发出什么事件
API
声明后端数据长什么样
