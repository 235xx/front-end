pinia笔记：
多个组件共享同一份数据

模块化优势：可以定义多个Store，代码结构更清晰
API风格和这是API非常接近

安装命令：pnpm install pinia

main.ts中
import { createPinia } from 'pinia'; // 1. 引入
const pinia = createPinia(); // 2. 创建 Pinia 实例
app.use(pinia); // 3. 挂载

定义store
Store 文件通常放在 src/stores/ 目录下
import { defineStore } from 'pinia';
export const useCounterStore = defineStore('counter', () => {
1.State(状态)
const count = ref(0)

2.Getters(计算属性)，推荐使用computed()来定义getters
const doubleCount = computed(()=> count.value \* 2)

3.Actions(方法)，推荐使用function()来定义actions
function increment(){
count.value++
}

return {
count,
doubleCount,
increment
}
})

使用store

1. 引入 Store
   import useCounterStore from '../store/useCounterStore'
2. 在组件中调用，获取 Store 实例
   Pinia 会自动处理，确保你在所有组件中获取的都是同一个实例
   const counterStore = useCounterStore();
3. 访问 State (可以直接解构，Pinia 做了处理)
   const { count, doubleCount, name } = counterStore;
   这样会失去响应性！
4. (推荐) 直接通过 store 实例访问
   counterStore.count
   counterStore.doubleCount
5. 调用 Actions
   function handleIncrement() {
   counterStore.increment();
   }
