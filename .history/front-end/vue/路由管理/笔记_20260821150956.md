路由笔记：

在App.vue里面，<router-link></router-link>里面是一个<a></a>，点击跳往对应链接。负责改变 URL，相当于导航按钮。
<router-view></router-view>里面渲染当前 URL 匹配到的组件

在index.ts里面，导入 import { createRouter, createWebHistory } from 'vue-router'
把createRouter()方法存到router变量中，并在最后默认导出default export
Router里面有history和routes两个属性，
history里面createWebHistory()，routes里面定义路由规则
routes里面的路由三个属性：path、name、component。分别是路径、名称和渲染的组件

在main.ts中，将Router挂载到Vue应用中
createApp(App)
.use(router)
.mount('#app')

动态路由：
/users/:id，这个:id是可以改变的
const route = useRoute()，通过useRoute()方法读取当前地址,需要写好导入import { useRoute } from 'vue-router'
然后再template里面route.params.id就能访问到当前地址的id，这个id通常是字符串不是数字。

useRouter()可以控制页面跳转，也需要写好导入import { useRouter } from 'vue-router'
const router = useRouter()
router.push('/about')

编程式导航：
有些跳转不是用户直接点击链接，而是执行完逻辑后自动跳转。
const router = useRouter()

function login() {
// 假设登录成功
localStorage.setItem('token', 'example-token')
router.push('/profile')
}

路由守卫：
router.beforeEach((to, from) => {
// to: 即将进入的目标路由对象
// from: 当前导航正要离开的路由对象

    // 检查路由是否需要登录
    if (to.meta.requiresAuth && !isLoggedIn()) {
      // 如果需要登录，但用户未登录
      // 1. 阻止本次导航
      return false;
      // 2. (或) 重定向到登录页
      // return { name: 'login' };
    }

    // 3. 如果不需要权限，或已登录，则放行
    return true;

});
